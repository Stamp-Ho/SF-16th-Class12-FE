# 아발론 빅박스 확장 규칙 및 조합

이 문서는 [기본 진행과 개발 설계](아발론%20게임%20규칙%20및%20개발%20설계.md)의 확장 규칙 명세다. **공식 규칙**과 이 서비스만의 **커스텀 직업 중첩**을 구분한다. 방장은 시작 전 사용할 직업·모듈을 고른다. 빅박스의 모든 직업·모듈을 구현 대상으로 삼되, 한 판에 전부 넣어야 한다는 뜻은 아니다.

## 1. 빅박스 직업 전부

| 직업 | 진영 | 공식 효과 |
| --- | --- | --- |
| 멀린 | 선 | 시작 시 악을 안다. 모드레드와 아래에 명시된 비공개 직업은 보이지 않는다. |
| 퍼시벌 | 선 | 멀린을 안다. 모르가나가 있으면 두 후보를 구분할 수 없다. |
| 충신 | 선 | 추가 능력 없음. |
| 성직자(Cleric) | 선 | 시작 리더의 진영을 안다. |
| 문제아(Troublemaker) | 선 | 진영을 조사받으면 반드시 거짓 진영으로 답한다. 실제 진영은 바뀌지 않는다. |
| 불신의 충신(Untrustworthy Servant) | 선 | 암살자를 안다. 멀린에게 악처럼 보인다. 원정에서는 선 규칙대로 성공만 낸다. 선 3승 뒤 암살자의 모집 대상이 될 수 있다. |
| 선 도적(Good Rogue) | 선 | 전용 성공 카드를 사용해 개인 승리를 노린다. |
| 선 마법사(Good Sorcerer) | 선 | 원정에서 마법 카드를 낼 수 있다. |
| 선 전령 2명(Good Messengers) | 선 | 각자 게임 중 최대 2번 선 전령 카드를 낼 수 있다. |
| 선 랜슬롯 | 시작 시 선 | 악 랜슬롯과 한 쌍. 변형 규칙에 따라 진영이 바뀔 수 있다. |
| 암살자 | 악 | 선 3승 뒤 멀린을 한 번 지목한다. |
| 모드레드 | 악 | 멀린에게 보이지 않는다. |
| 오베론 | 악 | 다른 악에게 보이지 않고 다른 악도 보지 못한다. 멀린에게는 보인다. |
| 모르가나 | 악 | 퍼시벌에게 멀린 후보로 보인다. 퍼시벌과 함께 사용한다. |
| 광인(Lunatic) | 악 | 참여한 원정마다 반드시 실패를 낸다. |
| 폭력배(Brute) | 악 | 1~3차 원정에서만 실패를 낼 수 있고, 어느 원정에서든 성공은 낼 수 있다. |
| 폭로자(Revealer) | 악 | 두 번째 원정 실패 직후 정체가 공개된다. |
| 사기꾼(Trickster) | 악 | 진영을 조사받으면 참/거짓 중 원하는 진영으로 답할 수 있다. 실제 진영은 바뀌지 않는다. |
| 악 도적(Evil Rogue) | 악 | 다른 악과 멀린에게 보이지 않으며 전용 실패 카드로 개인 승리를 노린다. |
| 악 마법사(Evil Sorcerer) | 악 | 성공 또는 마법만 낼 수 있고 일반 실패는 낼 수 없다. |
| 악 전령(Evil Messenger) | 악 | 악 전령 카드를 낼 수 있다. |
| 악 랜슬롯 | 시작 시 악 | 다른 악에게는 보이지만 자신은 다른 악을 모른다. 변형 규칙에 따라 진영이 바뀔 수 있다. |

빅박스는 멀린이 있는 게임에서 암살자 능력을 **다른 악 직업에 겸임**시킬 수 있다고 명시한다. 이 프로젝트는 이를 확장해 **멀린을 제외한 같은 진영 직업의 다중 중첩**을 지원한다. 진영 수는 기본 인원 표를 유지하며 중첩된 능력은 **한 사람·한 표·원정 카드 한 장**으로 계산한다.

### 불신의 충신과 암살

선 3승 뒤 암살자가 불신의 충신을 한 번 추측한다. 맞히면 그 사람이 악으로 모집되어 **암살을 대신 수행**한다. 틀리면 불신의 충신은 공개되지 않고 기존 암살자가 진행한다. 선 3승 전에 원정 카드는 언제나 선 기준으로 낸다.

## 2. 랜슬롯: 원정 카드 변형 선택과 공통 전환 시점

두 변형 모두 선 랜슬롯과 악 랜슬롯을 **서로 다른 두 플레이어**에게 하나씩 배정한다. 두 랜슬롯은 서로의 정체를 모른다. 시작 시 악 랜슬롯은 다른 악에게 보이지만 자신은 다른 악을 보지 못한다. 시작 정보는 이후 진영이 전환되어도 소급해서 다시 공개하지 않는다.

| 선택 | 충성심 카드 | 진영 전환 | 원정 카드 |
| --- | --- | --- | --- |
| 변형 1 | 2·3·4차 원정 뒤에 한 장씩 공개 | 공개 카드가 전환이면 두 랜슬롯의 현재 진영을 동시에 반대로 변경 | 현재 선은 성공만, 현재 악은 성공/실패 선택 |
| 변형 2 | 2·3·4차 원정 뒤에 한 장씩 공개 | 공개 카드가 전환이면 두 랜슬롯의 현재 진영을 동시에 반대로 변경 | 현재 선은 성공만, 현재 악 랜슬롯은 **실패만** |

두 변형 모두 이 서비스에서는 `변화 없음` 5장과 `진영 전환` 2장의 덱을 섞어 사용한다. 호수의 여인을 사용하는 방에서는 해당 원정의 여인 확인을 끝낸 **뒤** 카드 한 장을 뽑고, 뽑은 카드는 덱에 돌려놓지 않는다. 첫 드로우의 전환 확률은 2/7이며 이후 확률은 남은 카드에 따라 달라진다. 게임이 그 원정에서 끝나면 추가 드로우는 하지 않는다. 이는 공식 변형의 공개 시점을 변경한 서비스 규칙이다.

전환은 현재 진영, 원정 카드 제약, 최종 승리 진영에 적용한다. **직업 카드 자체와 시작 정보는 바뀌지 않는다.** 이 서비스는 현재 진영을 서버에 별도로 보관하고, 호수의 여인 등 진영 조사는 조사 시점의 현재 진영을 기준으로 한다.

## 3. 원정 카드와 개인 승리 모듈

### 도적(Rogues)

선/악 도적을 각각 또는 한쪽만 넣을 수 있다. 선 도적은 전용 성공, 악 도적은 전용 실패 카드를 낼 수 있으며 이 카드는 일반 성공/실패처럼 판정된다. 승인된 팀의 한 사람에게 감시 토큰을 주며, 5~6명 게임의 1·2차 원정에는 감시 토큰을 사용하지 않는다. 감시 대상 도적은 해당 원정에서 전용 카드를 낼 수 없다. 전용 카드 사용 여부는 원정 결과에 표시한다.

- 선 도적은 **세 번째 성공 원정**과 그보다 앞선 성공 원정에서 각각 전용 성공 카드를 냈다면 즉시 개인 승리한다.
- 악 도적은 **세 번째 실패 원정**과 그보다 앞선 실패 원정에서 각각 전용 실패 카드를 냈다면 즉시 개인 승리한다.
- 도적 개인 승리가 확정되면 암살 단계를 건너뛴다. 공식 규칙의 `5차 원정 후 자기 진영 승리` 부분 승리도 결과에 별도로 표시한다.

### 마법사(Sorcerers)

선/악 마법사를 **둘 다** 넣는다. 두 사람만 마법 카드를 낼 수 있다. 악 마법사는 일반 실패를 낼 수 없고 성공 또는 마법만 낸다. 원정의 기본 성공/실패를 먼저 판정한 뒤 마법 카드가 **홀수 장이면 결과를 한 번 뒤집고**, 짝수 장이면 원래 결과를 유지한다. 악 마법사가 시작 정보 단계에서 자신을 드러내지 않는 선택 규칙도 제공한다.

### 전령(Messengers)

선 2명과 악 1명을 **셋 다** 넣는다. 선 전령 카드는 성공, 악 전령 카드는 실패로 취급한다. 선 전령은 각자 최대 2번 전용 카드를 낼 수 있다. 각 원정의 전용 카드 장수를 공개 토큰으로 누적한다. **5차 원정 카드 공개 후** 선 토큰이 3개 이상이면 5차 원정의 실패 카드 1장을 제거할 수 있고, 악 토큰이 2개 이상이면 실패 카드 1장을 추가할 수 있다. 둘 다 충족하면 효과가 상쇄된다. 이후 원정 결과를 확정한다. 선 승리 시 암살자는 멀린 한 명 또는 **선 전령 두 명 모두** 중 어느 쪽을 목표로 할지 먼저 선언한다. 선 상급 전령이 하급 전령을 아는 선택 규칙도 제공한다.

## 4. 그 밖의 모든 선택 규칙과 모듈

| 모듈 | 공식 진행 |
| --- | --- |
| 호수의 여인 | 시작 리더의 오른쪽 사람이 토큰을 받는다. 2·3·4차 원정 직후 보유자가 한 사람의 진영만 비밀리에 확인하고 토큰을 넘긴다. 이전에 여인 능력을 사용한 사람은 조사 대상이 될 수 없다. |
| 목표 원정 선택(Targeting) | 아직 수행하지 않은 원정을 리더가 선택한다. 5차 원정은 다른 원정 2개 이상이 성공해야 선택 가능하다. 7명 이상 4차 원정의 실패 2장 규칙은 유지된다. |
| 함정꾼(Trapper) | 원정 팀을 평소보다 1명 크게 만든다. 원정 카드 제출 후 리더가 카드 한 장을 비밀리에 보고 제외한다. 남은 카드만 섞어 판정한다. |
| 엑스칼리버(Excalibur) | 팀 투표로 원정대가 확정된 뒤 리더가 자기 자신이 아닌 팀원 한 명에게 주거나 수여하지 않을 수 있다. 카드 제출 후 소유자는 다른 팀원 한 명의 제출 카드를 반대 카드로 바꾸고 **원래 카드**를 혼자 확인하거나 사용하지 않을 수 있다. 그 뒤 카드를 섞어 판정한다. |
| 플롯 카드(Plot) | 원정 시작마다 인원별 정해진 수를 리더가 다른 사람에게 나눠준다. 즉시/보유/게임 내내 유지하는 카드가 있으며 아래 표의 개별 효과를 따른다. |

### 플롯 카드 전부

5~6명 게임에서는 공식 5+ 카드 7장만, 7명 이상에서는 15장을 사용한다. 매 원정 시작 때 리더가 5~6명은 1장, 7~8명은 2장, 9~10명은 3장을 뽑아 **자기 이외**의 사람에게 순서대로 배분한다. 카드는 공개 정보다. 여러 카드가 동시에 사용 가능하면 리더부터 좌석 순서대로 처리하며, 같은 기회에 사용을 넘긴 뒤 다시 사용할 수 없다.

| 카드 | 효과 |
| --- | --- |
| Are You the One? | 받은 사람이 인접한 한 사람의 진영을 비밀 조사 |
| Charge! | 받은 사람은 다른 사람이 표를 고르기 전에 자기 투표를 공개. 게임 끝까지 유지 |
| Show Your Strength | 리더가 다른 한 사람에게 자신의 진영을 비밀 공개 |
| Show Your True Nature | 받은 사람이 자신이 고른 다른 한 사람에게 자신의 진영을 비밀 공개 |
| The King Returns | 승인된 팀을 다시 부결 처리. 5회 부결 승리 조건에 포함 |
| Ambush | 받은 사람이 제출된 원정 카드 한 장을 비밀 확인. 한 원정에서 같은 제출자의 카드를 여러 사람이 확인할 수 없음 |
| Lead to Victory | 현재 리더가 행동하기 전 사용해 리더가 됨. 투표 전에는 연달아 사용할 수 없음 |
| We Found You! | 팀원이 카드를 선택하기 전에 지정한 한 팀원의 원정 카드를 공개 제출하게 함 |
| Restore Your Honor | 다른 사람이 보유한 플롯 카드 한 장을 가져옴 |

카드의 **복본 수·5+/7+ 구분·즉시/보유/지속 유형**은 구현 시 공식 규칙서의 카드 목록을 데이터로 옮겨 검증한다. 이름이 9종이어도 실제 덱은 15장이다.

## 5. 커스텀 규칙: 직업 중첩

원작은 기본적으로 한 사람에게 한 직업 카드를 주지만, 이 서비스에서는 **멀린을 제외한 한 사람이 같은 진영의 직업 능력 여러 개**를 가질 수 있다. 예를 들어 `퍼시벌 + 충신`, `모르가나 + 암살자`, `모드레드 + 오베론 + 암살자`가 가능하다. 여러 직업을 받은 사람이 인원 표상 여러 명으로 계산되지는 않는다.

방장은 선·악의 자리별로 직업 묶음을 정한다. 묶음 하나가 해당 진영 자리 한 개를 차지한다. 선 랜슬롯과 악 랜슬롯은 반드시 별도 플레이어에게 배정한다. **누가 어느 묶음을 받는지는 서버가 진영 인원 표에 맞춰 무작위 배정**한다. 설정 단계에서 자리 수가 맞지 않거나 필수 짝이 빠진 모듈은 시작할 수 없다.

### 시작 정보는 능력별로 계산

1. 악끼리 서로 아는지는 **보는 사람**과 **보이는 사람**을 따로 계산한다. 오베론·악 랜슬롯·악 도적 등 `다른 악을 보지 못함` 효과가 보는 사람에게 있으면 목록이 비어 있다. 오베론·악 도적 등 `다른 악에게 보이지 않음` 효과가 대상에게 있으면 목록에서 제외한다.
2. 멀린에게는 악 후보를 보여주되 모드레드·악 도적 등 `멀린에게 보이지 않음` 효과가 있는 대상을 제외한다. 불신의 충신처럼 `멀린에게 악처럼 보임` 효과는 실제 선 진영과 독립적으로 적용한다.
3. 퍼시벌에게는 멀린과 모르가나 능력 보유자를 동일한 후보로 표시한다. 모르가나가 오베론과 중첩되어도 퍼시벌 속임수는 유지된다.
4. `모드레드 + 오베론`은 **본인은 다른 악을 못 보고, 다른 악도 본인을 못 보며, 멀린도 본인을 못 본다.** 암살자 능력을 함께 받더라도 이 가시성 규칙은 유지된다.
5. 직업 자체를 노출하는 공개 능력(예: 폭로자)은 가시성 은폐보다 나중에 발생하는 **게임 중 사건**이다. 시작 정보는 소급 변경하지 않는다.

### 조합 검증과 충돌

- 각 능력은 `시작 가시성`, `진영 조사 응답`, `원정 카드 허용`, `원정 후 사건`, `승리 조건`, `암살 권한`으로 분해한다. 서로 독립적인 능력은 모두 적용한다.
- **서로 동시에 만족할 수 없는 원정 카드 제약은 사전 거부**한다. 예: `광인 + 폭력배`는 4·5차 원정에서 실패가 필수이면서 금지되어 충돌한다. `광인 + 악 마법사`도 실패 필수/금지 충돌이다.
- 악 랜슬롯에 다른 악 능력을 중첩할 경우 **현재 진영이 악일 때만 악 전용 능력**을 사용한다. 진영 전환 후에도 이미 본 비밀 정보는 지울 수 없으므로, 설정 화면에 이 조합의 정보 비대칭을 알린다. 진영 조사와 최종 승리는 항상 현재 진영 기준이다.
- 위의 기본 조합 규칙으로 결정되지 않는 효과 선후관계는 임의로 처리하지 않는다. 방 시작 전 조합 검증에서 거부하고, 허용할 조합을 구현할 때 규칙과 테스트를 추가한다. 특히 `엑스칼리버 + 함정꾼 + 특수 원정 카드` 및 `모집 + 랜슬롯 진영 전환`은 별도 선후관계 테스트가 필요하다.

## 6. 구현 검증 항목

- 모든 직업·모듈을 단독으로 켜서 인원·진영 수와 필수 동반 직업을 검증한다.
- 시작 정보의 양방향 비대칭을 검사한다: 오베론, 모드레드, 악 도적, 악 랜슬롯, 불신의 충신, `모드레드 + 오베론`, `모르가나 + 오베론`.
- 랜슬롯 변형 1·2 각각 0·1·2회 전환, 전환 전후 원정 카드 및 여인 조사, 최종 승리 진영을 확인한다.
- 도적 개인 승리와 암살 생략, 전령의 5차 원정 보정, 마법 카드 홀짝, 엑스칼리버/함정꾼의 비밀 정보 경계, 플롯 카드 5회 부결을 확인한다.
- 모바일에서 손가락 터치만으로 모든 능력을 수행하고, 숨겨야 할 역할·카드가 공용 화면이나 Realtime payload에 나타나지 않는지 확인한다.
