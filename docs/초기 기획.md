# 📌 SSAFY 504 경매 & 좌석 배정 웹 서비스 기능 명세서 (PRD)

---

## 1. 개요 및 목표

- **목적:** 26명 규모의 소규모 인원이 자리 배정 및 다양한 항목에 대한 경매를 수행할 수 있는 웹 서비스
- **주요 특징:**
  - Admin 전용 관리 기능 및 일반 User 기능의 명확한 분리 (Admin은 모든 User 기능 포함)
  - 공지 및 Notion 링크 등을 자유롭게 등록하는 메인 대시보드
  - 범용적으로 재사용 가능한 경매 로직 (우선순위 1순위: 자리 배정 경매)
  - 멤버 26명의 순서를 무작위로 섞는 랜덤 순서 생성기

---

## 2. 사용자 및 권한 체계 (Role & Authorization)

### 2.1 권한 구조

- `User`: 기본 경매 참여, 자리 배정 참여, 내 입찰 내역 조회, 대시보드 링크 조회
- `Admin`: User의 모든 기능 + 회원 관리, 공지/링크 등록, 경매 생성 및 관리, 입찰 강제 제어

---

## 3. 기능 상세 명세 (Feature Specifications)

### 3.1 메인 대시보드 (Main Dashboard)

- **공용 링크 및 공지 관리 (Admin 전용 등록)**
  - Admin이 외부 링크(Notion 정리 페이지, 공지사항 등)를 자유롭게 추가/수정/삭제.
  - 모든 유저가 메인 화면에서 큼직한 버튼 형태 카드/링크로 쉽게 접근.
- **핵심 기능 바로가기 버튼:**
  - `자리 배정 경매` 바로가기
  - `일반 경매 목록` 바로가기
  - `순서 무작위 추첨 (Randomizer)` 바로가기
  - _(Admin 전용)_ `관리자 센터` 바로가기

### 3.2 회원 관리 (User Management) - Admin

- **Comma-Separated 일괄 회원 등록:**
  - 예: `홍길동, 김철수, 이영희, ...` 형태로 이름 목록을 입력받아 26명 계정 일괄 생성.
  - 기본 초기 비밀번호: `ssafy504`
- **권한 및 계정 제어:**
  - 회원 권한 변경 (`User` ↔ `Admin`)
  - 비밀번호 리셋 (특정 회원의 비밀번호를 `ssafy504`로 초기화)
  - 계정 활성화/비활성화 (차단)
- **회원 순서 랜덤 섞기 & 저장 (Randomizer & History):**
  - 전체 회원(Admin 포함 26명)의 이름/순서를 버튼 클릭 한 번으로 무작위 셔플.
  - **결과 저장 기능:** 추첨 제목(예: `"1차시 발표 순서"`, `"7/24 자리배정 순서"`) 및 설명과 함께 DB에 저장.
  - **히스토리 조회:** 과거 저장된 추첨 순서 리스트를 상시 조회 가능.

### 3.3 경매 엔진 (Auction Engine) & 자리 배정

- **자리 배정 경매 (Seat Allocation Auction):**
  - 고정 좌석 영역: `A` ~ `M` (총 13개 이상 구역/자리를 선택하여 선점)
  - 시작가: **0원**
  - 최소 입찰 단위: **500원** (0원 → 500원 → 1,000원 ...)
  - 차시(Round) 개념 관리 (예: 1차시 자리배정, 2차시 자리배정 등)
- **경매 로직 범용화 (Reusability):**
  - 동일한 입찰/검증/Realtime 로직을 자리 배정 외 물품 경매나 다른 기능에서도 활용 가능하도록 추상화.

## 4. 데이터베이스 스키마 설계 (Database Schema)

### 4.1 `users` (회원 정보)

| Column Name  | Type        | Description                       |
| :----------- | :---------- | :-------------------------------- |
| `id`         | UUID (PK)   | Supabase Auth ID                  |
| `name`       | TEXT        | 사용자 이름                       |
| `role`       | TEXT        | 권한 (`admin` \| `user`)          |
| `status`     | TEXT        | 계정 상태 (`active` \| `blocked`) |
| `created_at` | TIMESTAMPTZ | 생성 일시                         |

### 4.2 `dashboard_links` (대시보드 공지/링크)

| Column Name     | Type        | Description           |
| :-------------- | :---------- | :-------------------- |
| `id`            | UUID (PK)   | 고유 ID               |
| `title`         | TEXT        | 버튼/공지 제목        |
| `url`           | TEXT        | 연결 링크 (Notion 등) |
| `description`   | TEXT        | 부연 설명             |
| `display_order` | INT         | 노출 순서             |
| `created_at`    | TIMESTAMPTZ | 등록 일시             |

### 4.3 `seat_allocations` (자리 배정 현황)

| Column Name         | Type        | Description                 |
| :------------------ | :---------- | :-------------------------- |
| `id`                | UUID (PK)   | 고유 ID                     |
| `round_number`      | INT         | 차시 (예: 1차시, 2차시)     |
| `seat_code`         | TEXT        | 알파벳 구역 (`A` ~ `M`)     |
| `current_bidder_id` | UUID (FK)   | 현재 최고 입찰자            |
| `current_bid_price` | INT         | 현재 최고 입찰가 (기본값 0) |
| `is_closed`         | BOOLEAN     | 마감 여부                   |
| `updated_at`        | TIMESTAMPTZ | 최종 입찰 일시              |

### 4.4 `bids` (통합 입찰 히스토리 로그)

| Column Name    | Type        | Description                                  |
| :------------- | :---------- | :------------------------------------------- |
| `id`           | UUID (PK)   | 고유 ID                                      |
| `auction_type` | TEXT        | 입찰 종류 (`SEAT`, `ITEM` 등)                |
| `round_number` | INT         | 차시                                         |
| `target_id`    | TEXT        | 입찰 대상 (알파벳 코드 `A`~`M` 또는 물품 ID) |
| `bidder_id`    | UUID (FK)   | 입찰자                                       |
| `bid_price`    | INT         | 입찰 금액                                    |
| `created_at`   | TIMESTAMPTZ | 입찰 일시                                    |

### 4.5 random_draws (랜덤 추첨 이력 및 JSON 결과)

| Column Name | Type        | Description                                            |
| :---------- | :---------- | :----------------------------------------------------- |
| id          | UUID (PK)   | 고유 ID                                                |
| title       | TEXT        | 추첨 제목 (예: "1차시 자리배정 순서")                  |
| description | TEXT        | 메모 / 부연 설명                                       |
| result_data | JSONB       | 추첨 결과 데이터 [{"order": 1, "name": "홍길동"}, ...] |
| created_by  | UUID (FK)   | 추첨 실행 및 저장한 Admin                              |
| created_at  | TIMESTAMPTZ | 추첨 저장 일시                                         |
